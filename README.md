# Поиск по прайсу

Веб-приложение для поиска по прайсу из Excel: артикул и ключевые слова, фильтр по брендам, наценка, корзина, выгрузка и отправка прайса в xlsx.

Работает целиком в браузере, данные хранятся только на вашем устройстве.

## Использование
1. Откройте страницу и на вкладке «Прайс» загрузите файл .xlsx.
2. Ищите по артикулу или словам, добавляйте позиции в корзину, выгружайте список.
